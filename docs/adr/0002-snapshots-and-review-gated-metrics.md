# ADR 0002: Real SEC snapshots and reviewer-gated retrieval evaluations

**Decision (v0.7):** Store bounded sections extracted from genuine SEC filing HTML as accession-pinned, checksum-validated local snapshots. Separate *ingestion* from *question labeling*. Measure retrieval only when explicit reviewer-checked answers and evidence passage IDs are present; keep label `review_status=unreviewed` excluded and show a not-evaluated status rather than a zero or perfect score.

**Rationale:** Our earlier QA benchmarks were reconstructed numerical reference-table extracts. They demonstrated ranking behavior but not real filing ingestion or source-grounded qualitative QA. A fixed issuer-disjoint held-out split prevents reuse of company-specific facts from development cases. Reproducibility requires source accession numbers, text hashes, dataset hashes, and clearly stated annotation provenance.

**Alternatives rejected:** (1) Call autogenerated question/answer pairs gold labels without inspection. (2) Treat a checksum as independent SEC authentication. (3) Store credentials or private user prompts alongside sources. (4) Make runtime SEC requests from CI, causing flaky, rate-limited tests. (5) Automatically report a percentage even if no evidence labels have passed review.

**Limitations:** This pipeline cannot independently attest reviewer qualifications or correct semantics of human labels; it only enforces their declared status and source consistency. It does not ingest PDF-only sections, reproduce every SEC HTML layout, verify live model answers, or run across a large externally audited corpus. An external dataset and independent human review remain necessary.
